## Platform

web

Это настольное приложение для Windows 10/11 и macOS (Apple Silicon и Intel), но его окно — страница на HTML/CSS (папка `ui/`), показанная через pywebview: на Mac — системный WebKit, на Windows — WebView2, без WebView2 — встроенный Chromium. Поэтому `web`. Окно должно оставаться приложением, а не сайтом: без прокрутки всей страницы, родные сочетания клавиш, работа без интернета (шрифт лежит внутри), минимальный размер окна 760×560.

## Users

Авторы видео — сам автор или небольшая команда, — которые подбирают иллюстрации к каждому кадру сценария (познавательные ролики, видео для сна и т. п.). У них есть сценарий, разбитый на пронумерованные кадры, и к каждому кадру несколько поисковых запросов. Задача — быстро получить по нескольку подходящих картинок на каждый запрос, разложенных по номерам кадров, и не искать вручную.

Пользователи не технические: программу скачивают с GitHub, запускают двойным щелчком и работают в русском интерфейсе.

## Product Purpose

Программа принимает список кадров с запросами, ищет каждый запрос в Яндекс.Картинках через встроенный Chromium и скачивает первые подходящие картинки: не меньше 400 px по короткой стороне, без дублей. Имена файлов привязаны к кадру и запросу, а к каждому запуску прилагается CSV-отчёт об источниках.

Успех: пользователь вставил сценарий списком, нажал одну кнопку и получил готовую папку с картинками по кадрам без ручного поиска. Если работа прервалась, её можно просто запустить снова.

## Positioning

Пакетный поиск, устроенный вокруг кадров видеосценария: формат «номер — запрос|запрос|запрос», файлы с именами по кадрам, продолжение с места остановки и CSV с источником каждой картинки. Работает с выдачей Яндекса в настоящем браузере, поэтому капчу «Я не робот» человек проходит сам прямо в окне, и программа продолжает работу.

## Operating Context

- Список кадров обычно вставляется целиком из сценария («Вставить списком…»), одна строка — один кадр, запросы через `|`.
- Списки бывают длинными; работа идёт фоном, пока человек занят другим. Звуковой сигнал зовёт его, когда Яндекс просит капчу.
- Результаты: папка `Результаты/` (рядом с exe на Windows, в `Документы/Поиск картинок/` на Mac), дальше картинки уходят в монтаж.
- Распространение: релизы на GitHub (zip для Windows, dmg для Mac), без подписи разработчика, поэтому при первом запуске появляются предупреждения SmartScreen и Gatekeeper. Программа сама сообщает о новой версии.

## Capabilities and Constraints

- Настройки запуска: сколько картинок брать на запрос (1–20) и сколько браузеров запускать одновременно (1–4). Больше браузеров — чаще капча; рекомендуется 1–2.
- Ранее скачанные картинки пропускаются; список кадров сохраняется между запусками; журнал работы — `журнал.txt`.
- Всё нужное лежит внутри пакета (Python, библиотеки, Chromium), в систему ничего не устанавливается.
- Работа зависит от разметки страницы Яндекс.Картинок; если Яндекс её меняет, поиск может сломаться до выхода новой версии.
- Горячие клавиши должны работать и в русской раскладке (Cmd/Ctrl+V и т. п.); окно должно быть чётким на экранах Windows с масштабом 125–200%.
- Терминология: «кадр», «запрос», «браузеры сразу», «Результаты», «журнал».

## Brand Commitments

- Язык интерфейса и документации — русский; тон простой и конкретный, инструкции пошаговые, с точными названиями кнопок.

## Product Principles

1. **Справится человек без технических знаний.** Ни терминала, ни установки, ни непонятных слов; любое предупреждение ОС или ошибка объясняются по-русски вместе с тем, что нажать.
2. **Один путь от сценария до папки с картинками.** Вставить список → нажать «Найти» → открыть результаты. Всё остальное второстепенно.
3. **Остановка не страшна.** Прерванная работа продолжается повторным запуском, ничего не теряется и не скачивается дважды.
4. **Честно о том, что происходит.** Прогресс, капча, ошибки и новая версия видны в окне сразу, а не только в журнале.
5. **Источник каждой картинки прослеживается.** Права на картинки у их авторов; CSV-отчёт с адресами обязателен.

## Accessibility & Inclusion

Специальных требований не выдвигалось. Базовый уровень: читаемый текст при системном масштабировании, управление с клавиатуры, работающее в любой раскладке.

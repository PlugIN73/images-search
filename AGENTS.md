# Выпуски

- В `packaging/release-notes.md` каждого релиза обязателен раздел «Как пользоваться» с пошаговой инструкцией.
- Перед публикацией проверяйте описание командой `python packaging/check_release_notes.py`.
- Инструкция внутри Windows-пакета также должна объяснять использование программы.
- При обновлении Windows нужно переносить целиком `Результаты` и `_internal\данные` до первого запуска новой версии.
- `_internal\данные` содержит список кадров, настройки и профили браузера с сохранёнными входами. Переносить весь `_internal` нельзя.

# Поиск картинок в Яндексе

Программа берёт список кадров с поисковыми запросами, ищет каждый запрос в Яндекс.Картинках и скачивает первые подходящие картинки (не меньше 400 px по короткой стороне, без дублей). К каждому запуску прилагается CSV-отчёт: какой файл, по какому запросу и откуда скачан.

## Скачать

👉 **[Последняя версия](https://github.com/PlugIN73/images-search/releases/latest)**: Windows 10/11 и macOS (Apple Silicon и Intel). Ничего дополнительно ставить не нужно: Python, библиотеки и браузер Chromium уже внутри пакета. Программа ничего не устанавливает в систему, и чтобы её удалить, достаточно удалить папку (Windows) или приложение (Mac).

Как скачать и запустить, подробно описано на странице релиза. Если коротко:

- **Windows:** распакуй zip, запусти `Poisk-kartinok.exe`. На предупреждение SmartScreen нажми «Подробнее» → «Выполнить в любом случае».
- **Mac:** перетащи приложение из `.dmg` в «Программы». При первом запуске открой «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».

Предупреждения появляются потому, что программа не подписана платным сертификатом разработчика. Это делается один раз.

Окно программы на Windows работает через WebView2 — он есть в Windows 11 и почти во всех Windows 10. Если его нет, окно откроется во встроенном браузере Chromium: выглядит так же, работает так же.

## Как пользоваться

1. **«Вставить списком»**: одна строка равна одному кадру, запросы перечисляются через `|`:
   ```
   53 - кот на подоконнике|кот у окна|кошка подоконник солнце
   54 - старый трамвай зимой|трамвай снег город
   ```
   Номер кадра попадает в столбец «Кадр» и в имена файлов: `53 - кот на подоконнике-1.jpg`. Если у строки нет номера, программа даст ей следующий свободный. Кадры можно добавлять и по одному кнопкой «+ Кадр», номер подставится сам. Чтобы поправить номер или запросы, просто щёлкни по ним.
2. Внизу, рядом с кнопкой «Найти картинки», укажи кнопками − и +, сколько картинок брать на запрос и сколько браузеров запускать одновременно. Больше браузеров работают быстрее, но Яндекс чаще просит капчу. Рекомендую 1–2.
3. **«Найти картинки»** (или Cmd+Enter / Ctrl+Enter). Над кнопками видно, сколько кадров уже готово и сколько примерно осталось, а у каждого запроса появляются маленькие превью скачанных картинок. Если Яндекс спросит «Я не робот», раздастся звук и появится жёлтая плашка: поставь галочку в окне браузера, и программа продолжит сама.
4. **«Открыть папку»**. Если по каким-то запросам ничего не нашлось, программа назовёт их в итоге поиска и отметит в списке. Щелчок по превью открывает картинку.

Картинки, скачанные раньше, программа пропускает, поэтому после остановки её можно просто запустить снова. Список кадров сохраняется между запусками.

**Где лежат данные:**
- **Windows:** картинки и CSV-отчёты лежат в папке `Результаты\` рядом с `Poisk-kartinok.exe`. Служебные файлы (журнал, список кадров, профили браузера) хранятся в `_internal\данные\`. Если в папку программы писать нельзя (например, она лежит в `C:\Program Files`), всё уходит в `Документы\Поиск картинок\`.
- **Mac:** `Документы/Поиск картинок/`. Там лежат `Результаты/`, `журнал.txt`, список кадров и профили браузера.

**Обновление на Windows:** распакуй новую версию и перенеси в неё папку `Результаты` из старой. Чтобы сохранить список кадров, перенеси ещё и `_internal\данные`.

Новую версию программа замечает сама: в правом верхнем углу появится ссылка «Вышла версия … — скачать».

## Частые проблемы

| Что случилось | Что делать |
|---|---|
| «не смог запустить браузер» | Скачай программу заново: скорее всего, архив распаковался не полностью или антивирус удалил часть файлов. |
| Windows: картинки не сохраняются | Защитник Windows → «Защита от программ-шантажистов» → «Контролируемый доступ к папкам»: разреши `Poisk-kartinok.exe`. |
| «браузер с этим профилем уже открыт» | Программа запущена дважды, закрой лишнюю копию. |
| Капча на каждом запросе | Уменьши число браузеров до 1 и сделай перерыв. |
| Всё перестало находиться | Возможно, Яндекс поменял страницу. Проверь, нет ли новой версии, или [напиши об ошибке](https://github.com/PlugIN73/images-search/issues), приложив `журнал.txt` (на Windows он лежит в `_internal\данные`). |

Картинки в выдаче принадлежат их авторам. Перед использованием в публикациях проверяй права: адрес источника каждой картинки есть в CSV-отчёте.

## Для разработчика

```
okno.py          запуск: открывает окно (pywebview, запасной вариант — встроенный Chromium)
ui/              само окно: страница на HTML/CSS/JS и шрифт Onest
most.py          мост между окном и программой: маленький сервер на 127.0.0.1
kadry.py         список кадров: разбор вставки, номера кадров, имена файлов
poisk.py         поиск, скачивание, выбор браузера, проверка обновлений
packaging/       сборка пакетов (PyInstaller)
.github/workflows/build.yml   сборка в GitHub Actions
```

**Запуск из исходников на Mac:** `Запустить.command`. Он сам поставит `uv`, Python 3.11 и зависимости в `~/.poisk-kartinok/venv`. При таком запуске данные хранятся рядом с программой, а не в «Документах».

**Сборка локально:**
- Mac: `bash packaging/build_mac.sh` → `dist/*.dmg` (собирается под архитектуру этого Mac).
- Windows: `powershell -ExecutionPolicy Bypass -File packaging\build_windows.ps1` → `dist\*.zip`.

Оба скрипта в конце запускают собранную программу с ключом `--self-test`: проверяют браузер, окно, Pillow и пробный поиск в Яндексе. Если что-то не работает, сборка падает.

**Выпуск новой версии:**
1. Поменяй `ВЕРСИЯ` в `poisk.py` (например, на `1.1.0`).
2. Закоммить и отправь тег:
   ```bash
   git tag v1.1.0 && git push origin main v1.1.0
   ```
3. GitHub Actions соберёт пакеты для Windows, Mac Apple Silicon и Mac Intel, проверит их и опубликует релиз. У пользователей появится уведомление об обновлении.

Чтобы просто проверить сборку без релиза: Actions → «Сборка» → Run workflow. Пакеты появятся в артефактах запуска.

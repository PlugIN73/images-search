ПОИСК КАРТИНОК — как запустить

1. Если вы видите этот файл внутри архива — сначала распакуйте архив:
   правой кнопкой по zip-файлу → «Извлечь всё…» → «Извлечь».
   Из архива программа не запустится.

2. В распакованной папке запустите Poisk-kartinok.exe.

3. Если Windows пишет «Windows защитила ваш компьютер» —
   нажмите «Подробнее» → «Выполнить в любом случае».

Программа ничего не устанавливает: браузер и всё нужное лежит в этой папке.
Чтобы удалить программу — удалите папку.

Картинки и отчёты: кнопка «Открыть папку с результатами» в окне программы.
Подробности: https://github.com/PlugIN73/images-search

ПОИСК КАРТИНОК — как запустить

1. Если ты видишь этот файл внутри архива, сначала распакуй архив через «Извлечь всё».
2. В распакованной папке запусти Poisk-kartinok.exe.
3. Если SmartScreen показывает предупреждение, выбери «Подробнее» → «Выполнить в любом случае».

КАК ПОЛЬЗОВАТЬСЯ

1. Нажми «Вставить списком». Одна строка — один кадр; запросы разделяются символом |.
   Пример: 53 - кот на подоконнике|кот у окна|кошка на солнце
2. Выбери количество картинок на запрос и число браузеров. Начни с 1–2 браузеров.
3. Нажми «Найти картинки». Если Яндекс попросит проверку «Я не робот», пройди её в окне браузера.
4. Нажми «Открыть папку», чтобы увидеть изображения и CSV-отчёт с источниками.

Список кадров → Настройки → Поиск → Результаты

После остановки можно снова запустить поиск. Скачанные картинки программа пропустит.

ОБНОВЛЕНИЕ БЕЗ ПОТЕРИ ДАННЫХ

1. Закрой старую программу и все её окна браузера. Сохрани копию старой папки программы.
2. Распакуй новую версию отдельно. Пока не запускай её.
3. Скопируй из старой папки в новую ОБЕ папки ЦЕЛИКОМ:
   Результаты         → Результаты
   _internal\данные   → _internal\данные
4. Проверь расположение: Poisk-kartinok\_internal\данные рядом с новым Poisk-kartinok.exe.
5. Запусти новую версию и проверь список кадров и сохранённые входы до начала поиска.

Закрыть → Резервная копия → Перенос двух папок → Запуск → Проверка

Папка «_internal\данные» содержит список кадров, настройки, журнал и профили браузера с авторизациями.
Перенос только «Результаты» НЕ сохраняет входы в новой папке программы.
Не копируй весь «_internal»: в новой версии должны остаться новые библиотеки и браузер.
Не удаляй старую папку и резервную копию, пока не проверишь обновление.

Если данные были в «Документы\Поиск картинок», укажи эту папку через POISK_DATA перед запуском новой версии.
Если POISK_DATA уже настроена, сохрани прежнее значение. Выбранная папка видна в журнале.

ГДЕ ЛЕЖАТ ДАННЫЕ

Обычно картинки и отчёты находятся в «Результаты» рядом с программой.
Служебные данные находятся в «_internal\данные».
Если рядом с программой писать нельзя, данные находятся в «Документы\Поиск картинок».
При заданной POISK_DATA используется указанная папка; результаты лежат в её подпапке «Результаты».

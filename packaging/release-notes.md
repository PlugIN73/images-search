## Что изменилось в 1.0.3

- Исправлена инструкция обновления Windows: переносить нужно результаты и всю папку данных с профилями браузера.
- Добавлена пошаговая инструкция использования в описание релиза и внутрь Windows-пакета.
- Выпуск без раздела «Как пользоваться» теперь блокируется автоматически.
- Chrome for Testing **157.0.8103.38** работает с включённой песочницей.

## Какой файл скачать

| Компьютер | Файл |
|---|---|
| Windows 10 / 11 | `Poisk-kartinok-1.0.3-windows.zip` |
| Mac с Apple Silicon (M1 и новее) | `Poisk-kartinok-1.0.3-mac-arm64.dmg` |
| Mac с Intel | `Poisk-kartinok-1.0.3-mac-x86_64.dmg` |

Тип Mac указан в меню Apple → «Об этом Mac»: «Чип Apple» означает Apple Silicon, «Процессор Intel» — Intel.

## Первый запуск

**Windows:** распакуй ZIP через «Извлечь всё» и запусти `Poisk-kartinok.exe` из распакованной папки.
Из архива программу не запускай.
Если SmartScreen показывает предупреждение, выбери «Подробнее» → «Выполнить в любом случае».

**Mac:** открой DMG и перетащи «Поиск картинок» в «Программы».
При предупреждении о неизвестном разработчике открой «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
Программа пока не подписана сертификатом разработчика.

Если обновляешь существующую версию, сначала выполни раздел обновления ниже.

## Как пользоваться

1. Нажми **«Вставить списком»**. Одна строка задаёт один кадр, а символ `|` разделяет поисковые запросы.

   ```text
   53 - кот на подоконнике|кот у окна|кошка на солнце
   54 - старый трамвай зимой|трамвай снег город
   ```

2. Выбери количество картинок на запрос и число браузеров. Начни с одного или двух браузеров.
3. Нажми **«Найти картинки»**. Программа покажет ход поиска и превью найденных изображений.
4. Если Яндекс спросит «Я не робот», пройди проверку в окне браузера. Программа продолжит поиск автоматически.
5. Нажми **«Открыть папку»**, чтобы увидеть картинки и CSV-отчёт с адресами источников.

```text
Список кадров → Настройки → Поиск → Проверка Яндекса при необходимости → Результаты
```

Номера и запросы можно править прямо в списке. Новый кадр добавляется кнопкой «+ Кадр».
После остановки можно повторно запустить поиск: ранее скачанные картинки программа пропустит.
Перед публикацией изображений проверь права на них по источникам из CSV-отчёта.

## Обновление Windows без потери данных

1. Закрой старую программу и все её окна браузера. Сохрани резервную копию старой папки программы.
2. Распакуй новую версию в отдельную папку. Пока не запускай её.
3. Скопируй из старой папки в новую **обе папки целиком**: `Результаты` и `_internal\данные`.
4. Проверь путь: папка данных должна находиться рядом с новым EXE как `Poisk-kartinok\_internal\данные`.
5. Запусти новую программу. Проверь список кадров и сохранённые входы перед началом поиска.

```text
Закрыть → Резервная копия → Перенос двух папок → Запуск → Проверка

Старая папка                        Новая папка
Результаты                  →      Результаты
_internal\данные            →      _internal\данные
```

В `_internal\данные` находятся список кадров, настройки, журнал и профили браузера с сохранёнными входами.
**Не копируй весь `_internal`:** сохрани новые библиотеки и браузер из нового пакета.
Перенос только `Результаты` не переносит профили и авторизации.

Если старая версия сохраняла данные в `Документы\Поиск картинок`, укажи эту папку через переменную `POISK_DATA` перед запуском новой версии.
Если `POISK_DATA` уже настроена, сохрани её прежнее значение.
Выбранная папка данных указана в журнале программы.
Не удаляй старую папку и резервную копию до проверки обновления.

## Обновление Mac

Закрой программу и её окна браузера. Сохрани копию папки `Документы/Поиск картинок`.
Замени приложение в «Программах» новой версией из DMG.
Папку данных оставь на месте; проверь список кадров и входы после запуска.
При запуске из исходников данные остаются рядом с исходниками.
Если задана `POISK_DATA`, сохрани прежнее значение.

## Где находятся результаты

- **Windows:** `Результаты` рядом с `Poisk-kartinok.exe`; служебные данные — `_internal\данные`.
- **Mac:** `Документы/Поиск картинок/Результаты`.
- При заданной `POISK_DATA` результаты находятся в подпапке `Результаты` указанной папки.

Если программа сохраняет данные в другую папку, ориентируйся на путь в журнале.
Для отката используй резервную копию профиля, созданную до обновления браузера.
